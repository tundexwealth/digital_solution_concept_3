# Concept 3 — Bold / Creative

Four separate responsive pages are implemented: Home, About, Services, and Contact. This concept uses an expressive studio direction: oversized centered video hero type, warm neutral surfaces, restrained lime accents, and deliberately varied section compositions. Its typography and layouts distinguish it from the other two concepts while keeping the brief’s professional presentation and the Avo template’s image-led project storytelling.

The homepage hero uses the provided muted looping video at `assets/video/nexora-home-hero.mp4` as its only background media. Selected Avo demo photos are used in the company introduction, project examples, team-photo placeholders, and as a subtle background on the three interior pages. The Avo template code was not copied into this concept. Project examples, metrics, testimonials, and contact details are editable placeholders. The contact form validates required fields in the browser and displays “Successfully filled form.” It does not send submissions.

The included Avo demo photos are for preview use; replace them with company-owned or properly licensed photos before public production deployment.
